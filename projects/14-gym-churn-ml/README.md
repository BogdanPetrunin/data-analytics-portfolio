# Прогнозирование оттока клиентов фитнес-клуба

## Задача

Построить модель машинного обучения, которая оценивает вероятность ухода клиента в следующем месяце. Это помогает отделу удержания заранее выбрать клиентов для персональных предложений.

Проект демонстрирует полный цикл ML-аналитики:

- подготовка и проверка данных;
- разделение на train/test;
- построение baseline и моделей Logistic Regression и Random Forest;
- подбор порога классификации;
- оценка ROC-AUC, precision, recall и F1;
- интерпретация факторов риска.

## Данные

В проекте используется воспроизводимый генератор учебного набора данных. Такой формат позволяет запустить проект без скачивания внешних файлов и отдельно показать логику подготовки признаков. Для реального внедрения генератор заменяется выгрузкой из CRM.

Признаки клиента: возраст, длительность договора, число посещений за месяц, среднее число дней с последнего визита, наличие автоплатежа, обращения в поддержку и удовлетворённость.

## Стек

Python, pandas, numpy, scikit-learn, matplotlib, seaborn.

## Запуск

```bash
pip install -r requirements.txt
python train.py
```

Скрипт создаст данные, обучит две модели и сохранит метрики и графики в папку `artifacts/`.

## Результат

Основная метрика — ROC-AUC. Для задачи удержания дополнительно контролируется recall: пропустить уходящего клиента обычно дороже, чем связаться с клиентом, который всё-таки остался.

После запуска в `artifacts/metrics.json` будут доступны фактические значения метрик, а в `artifacts/feature_importance.png` — вклад признаков. Числа намеренно не зафиксированы в README: они пересчитываются при каждом запуске из заданного random seed.
