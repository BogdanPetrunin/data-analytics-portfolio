# Анализ активности доноров крови (DonorSearch)

**Цель:** проанализировать регистрацию и активность доноров, динамику донаций за 2022–2023 годы, влияние бонусной системы и соотношение плановых и фактических донаций.

**Стек:** SQL, CTE, оконные функции, работа с датами

**Что сделано:**
- Регионы с наибольшим числом зарегистрированных доноров.
- Динамика количества донаций по месяцам за 2022–2023 годы.
- Топ-100 самых активных доноров по числу подтверждённых донаций.
- Влияние бонусной системы на среднее число донаций.
- Когортный анализ доноров по году первой донации и частоте донаций.
- Сравнение запланированных и фактически совершённых донаций (completion rate по типу донации).

**Файлы:** `analysis.sql` — восемь SQL-запросов (кейсов) с комментариями по каждой задаче.
