# Активность доноров крови на платформе DonorSearch

**Задача.** Оценить, как доноры регистрируются и сдают кровь: где их больше всего, как меняется число донаций, работает ли бонусная программа, из каких каналов приходят самые активные доноры и насколько доноры выполняют собственные планы.

**Данные.** PostgreSQL-схема `donorsearch`: анонимизированные профили доноров, бонусы, совершённые и запланированные донации.

**Стек.** PostgreSQL: CTE, оконные функции, `CASE`, работа с датами (`DATE_TRUNC`, `EXTRACT`), `LEFT JOIN` для сопоставления плана и факта.

## Что исследовал

1. Регионы с наибольшим числом доноров.
2. Помесячная динамика донаций за 2022–2023 годы.
3. Топ-100 доноров по подтверждённым донациям.
4. Среднее число донаций у доноров с бонусами и без.
5. Каналы регистрации (VK, OK, Яндекс, Telegram, Google) и активность доноров из каждого.
6. Когорты повторных доноров по году первой донации: частота, длительность активности, средний интервал между донациями.
7. План vs факт: доля выполненных запланированных донаций по типу донации.
8. Распределение доноров по полу.
