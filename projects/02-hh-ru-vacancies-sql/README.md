# Анализ вакансий аналитиков данных на HH.ru

**Цель:** изучить рынок труда для аналитиков данных и системных аналитиков — зарплаты, регионы, работодателей, требуемый опыт и навыки.

**Стек:** SQL

**Ключевые результаты:**
- Средняя предлагаемая зарплата — от ≈110 000 до ≈154 000 руб.
- Лидеры по числу вакансий — Москва (1247) и Санкт-Петербург (181).
- Крупнейший работодатель — СБЕР (243 вакансии), далее Wildberries, Ozon, ВТБ.
- 64% вакансий рассчитаны на уровень Junior+, 26% — Middle, на Senior приходится менее 1%.
- Топ ключевых навыков: анализ данных, SQL, MS SQL; Python отдельно почти не упоминается, хотя часто подразумевается под «анализом данных».

**Файлы:** `analysis.sql` — запросы с результатами и комментариями по каждому пункту анализа.
