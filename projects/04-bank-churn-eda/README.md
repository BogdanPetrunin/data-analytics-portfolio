# EDA: профиль нелояльных клиентов банка «Метанпром»

**Цель:** провести разведочный анализ данных клиентов банка и определить портрет клиентов, склонных уходить из банка (отток, признак `Churn`).

**Стек:** Python (pandas, matplotlib, seaborn, phik)

**Что сделано:**
- Загрузка и первичное знакомство с двумя датасетами (10 000 клиентов).
- Предобработка: приведение названий столбцов к единому стилю (snake_case), оптимизация типов данных, анализ пропусков (36% пропусков в столбце `balance`) с проверкой гипотез о причинах.
- Исследовательский анализ связи признаков клиентов с оттоком, построение корреляционной матрицы (phik — для смеси числовых и категориальных признаков).
- Формулирование портрета клиентов с повышенным риском ухода из банка.

**Файлы:** `EDA_Metanbank_full.ipynb` — полный ноутбук с кодом, визуализациями и выводами.
