# EDA: рынок общественного питания в Москве

**Цель:** провести исследовательский анализ рынка общепита Москвы (данные за 2022 год), чтобы помочь инвесторам выбрать тип и локацию будущего заведения.

**Стек:** Python (pandas, matplotlib, seaborn, phik)

**Что сделано:**
- Анализ категорий заведений и их географического распределения по районам.
- Соотношение сетевых и несетевых заведений.
- Анализ количества посадочных мест и рейтингов заведений.
- Поиск корреляции рейтинга с другими параметрами.
- Топ-15 популярных сетей и их рейтинги.
- Анализ среднего чека по районам.

**Файлы:** `проект_рынок_общественного_питания.ipynb` — полный ноутбук с кодом, визуализациями и итоговыми выводами.
