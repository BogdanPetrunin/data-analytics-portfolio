# Рынок общественного питания Москвы

> 🚧 **Проект в работе.** Сейчас в ноутбуке — постановка задачи, описание данных и загрузка. Анализ и выводы появятся по мере выполнения.

**Задача.** Исследовать рынок общепита Москвы (данные за 2022 год), чтобы помочь инвесторам выбрать формат и район для нового заведения.

**Данные.** Заведения общепита Москвы: категория, район, адрес, часы работы, рейтинг на Яндекс Картах, сетевое или нет, количество мест, ценовая категория и средний чек.

**Стек.** Python: pandas, matplotlib, seaborn, phik.

## План анализа

- Категории заведений и их распределение по административным округам.
- Сетевые и несетевые заведения.
- Посадочные места и рейтинги по категориям.
- Какие параметры связаны с рейтингом (`phi_k`).
- Топ-15 сетей по числу заведений и их рейтинги.
- Средний чек по округам.
