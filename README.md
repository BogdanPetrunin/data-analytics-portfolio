## Навыки

- **SQL (PostgreSQL):** JOIN, CTE, оконные функции, агрегаты, `PERCENTILE_DISC`, `FILTER`.
- **Python:** pandas (предобработка, группировки, сводные таблицы, объединение таблиц), numpy, matplotlib, seaborn, phik.
- **Анализ:** EDA, проверка качества данных, пропуски и аномалии (IQR), сегментация, корреляционный анализ, анализ динамики, выводы и рекомендации для бизнеса.
- **Инструменты:** Jupyter Notebook, DBeaver, DataLens, Git/GitHub, Excel.

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook
```

Данные для проекта по стартапам лежат в репозитории, для проекта по банку загружаются по ссылке прямо в ноутбуке. SQL-проекты выполнялись в PostgreSQL на учебной базе, результаты запросов приведены в комментариях.
