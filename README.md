# Портфолио по анализу данных — Богдан Петрунин

Учебные и практические проекты по анализу данных: SQL и Python (pandas, EDA, статистика).
Материалы выполнены в рамках курса «Аналитик данных» (Яндекс Практикум) и дополнительных кейсов.

## Проекты

| # | Проект | Стек | Что сделано |
|---|--------|------|-------------|
| 1 | [Покупки в мобильной игре «Секреты Тёмнолесья»](projects/01-game-purchases-sql) | SQL (PostgreSQL) | Анализ платящей аудитории и внутриигровых покупок |
| 2 | [Вакансии аналитиков на HH.ru](projects/02-hh-ru-vacancies-sql) | SQL | Анализ рынка труда: зарплаты, регионы, навыки |
| 3 | [Активность доноров DonorSearch](projects/03-donorsearch-sql) | SQL | Динамика донаций, когортный анализ, бонусная система |
| 4 | [Отток клиентов банка «Метанпром»](projects/04-bank-churn-eda) | Python (pandas, EDA) | Портрет клиентов, склонных уходить из банка |
| 5 | [Рынок общепита Москвы](projects/05-moscow-restaurants-eda) | Python (pandas, EDA) | Анализ заведений общественного питания |

## Стек

SQL (PostgreSQL), Python (pandas, matplotlib, seaborn, phik), Jupyter Notebook.
