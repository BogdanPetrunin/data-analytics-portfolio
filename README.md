# Портфолио аналитика данных — Богдан Петрунин

Начинающий аналитик данных из Екатеринбурга. Учусь в УрФУ на «Бизнес-информатике» и прохожу расширенный курс «Аналитик данных» в Яндекс Практикуме (до февраля 2027).

**Ищу стажировку или junior-позицию аналитика данных** — в Екатеринбурге или удалённо.

В проектах отвечаю на бизнес-вопросы с помощью SQL, Python и BI: от сырых данных и их проверки до выводов и рекомендаций для заказчика. В каждой папке есть README с задачей, данными, ходом работы, графиками и выводами. Все проекты учебные, на учебных данных.

## Навыки

- **SQL (PostgreSQL):** JOIN, CTE, подзапросы, оконные функции, агрегаты, `PERCENTILE_CONT`/`PERCENTILE_DISC`, `FILTER`, `CASE`.
- **Python:** pandas, numpy, matplotlib, seaborn, scipy, statsmodels, phik.
- **Статистика:** A/B-тесты (расчёт размера выборки, проверка баланса групп, z-тест для долей), t-тесты, проверка гипотез, нормальное распределение, доверительные интервалы.
- **Продуктовая аналитика:** DAU, конверсия, средний чек, Retention, LTV.
- **BI и таблицы:** Yandex DataLens (дашборды, чарты, QL-запросы), Google Таблицы.
- **Анализ:** EDA, проверка качества данных, пропуски и аномалии (IQR), сегментация, корреляционный анализ, выводы и рекомендации для бизнеса.
- **Инструменты:** Jupyter Notebook, DBeaver, Git/GitHub.

